# Nuzlocke Tracker — Ideen

Sammelstelle des **Innovator**-Subagents (siehe `CLAUDE.md` → "Subagent-Rollen"). Hier landen
neue Ideen jeder Art — Features, Quality of Life, bessere Technologien, neue Werkzeuge, Sonstiges.

**Ablauf:**
1. Innovator trägt eine Idee unter "Neu" ein (Format unten). Er setzt NIE selbst um.
2. Der Projektleiter-Chat liest diese Datei und legt die Ideen dem Nutzer vor.
3. Nur mit Genehmigung des Nutzers wird daraus ein Task in `TASKS.md`; die Idee wandert dann nach
   "Genehmigt" (mit Task-Nummer). Abgelehnte Ideen wandern nach "Abgelehnt" (mit kurzem Grund),
   damit sie nicht erneut vorgeschlagen werden. Nichts wird gelöscht.
4. Vor dem Eintragen prüfen, ob die Idee schon in `BACKLOG.md` steht — dann nur darauf verweisen.

**Format pro Idee:**
```
- **<Kurztitel>** (Kategorie: Feature / QoL / Technologie / Werkzeug / Sonstiges)
  Nutzen: ... | Aufwand: klein/mittel/groß | Risiken: ... | Bezug: BACKLOG.md-Punkt oder "neu"
  (vorgeschlagen: Innovator, YYYY-MM-DD)
```
